누가 쓰나

iBD 팀원 3~5명. 금요일 데모데이에 프로젝터로 다 같이 띄워놓고 발표 순서대로 연다. 18주 내내 같은 화면.

없앨 동작 하나

제출이라는 동작 자체. report 복사 → 시트 붙여넣기를 "URL 드랍 5초"로 줄인다.

핵심 기능 1개

배포 URL을 드랍하면 그 사이트의 기획서(/docs/plan.html)를 읽어 카드로 저장된다. 폴더 규약이 곧 데이터 소스다. 기획서가 없는 URL도 도메인 카드로 저장된다 — 드랍 실패는 없다.

안 만드는 것 3개

  • 스택별 필터 — 갤러리 v2 과제
  • 검색 — 100장 남짓, 스크롤로 충분
  • 수정·삭제 UI — 로그인 없는 사이트에 삭제 버튼은 무방비

내 옵션 + 이유

Vercel — 서버 함수(기획서 읽기)가 필요하고, 주 1회 열리는 화면이라 콜드스타트 없는 호스트여야 한다(Render 탈락). 레지스트리는 가이드 허용 조항에 따라 시트 → DB(Supabase)로 교체.

리스크 + 검증법

스파이크로 검증 완료: 서버 함수의 외부 fetch / DB insert·select / 키 비노출. 남은 리스크는 팀 템플릿 미확정 — <title> 폴백으로 대응.
