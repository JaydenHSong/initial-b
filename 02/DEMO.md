# S02 데모 — 클릭 순서 (3분)

1. https://initial-b02.vercel.app 열기
2. 「+ 제품 추가」 → 아마존 상품 URL 붙여넣기 → 태그 타이핑하다 `Tab`으로 자동완성 → 등록
3. 칩 `무선` + `보안카메라` → 상태줄 읽기 → **「하나라도 (OR)」 눌러 같은 줄 다시 읽기**
4. 카드의 「가격 기록 · 목표가」 → 요약·증감·읽기 횟수 보고, 목표가를 현재가보다 높게 저장
5. `/api/cron?key=…` 열고 Google Chat으로 전환 → 알림 확인

---

3번에서 나오는 두 줄 (이번 주 리포트의 핵심)

```
모두 (AND)    서버가 2개를 돌려주고 1개를 버렸다 — 버린 것도 읽기 요금
하나라도 (OR) 서버가 2개를 정확히 돌려줬다 — 버린 것 0 (array-contains-any)
```
