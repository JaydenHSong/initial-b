# S02 데모 — 클릭 순서 (3분)

1. https://initial-b02.vercel.app 열기 — 카드 그리드, 태그 칩 줄
2. 아마존 상품 URL 붙여넣기 → 「기존 태그」에서 `무선` 클릭 → 새 태그 하나 타이핑 → 등록
3. 칩 `무선` + `보안카메라` 동시 클릭 → 윗줄 "서버가 N개 돌려주고 M개가 정답, N-M개는 버렸다" 읽기
4. 카드 클릭 → 뒤집힌 뒷면에서 가격 기록과 "이 카드 하나에 문서 N회 읽음" 보고, 목표가를 현재가보다 높게 넣고 저장
5. `/api/cron?key=…` 열고 Google Chat 스페이스로 전환 → 목표가 도달 알림 확인
