한 줄 결론

서버리스 앱에서 형태가 정해진 LLM 출력(요약·분류·추출)이 필요하면 Anthropic SDK 직접 + 구조화 출력을 쓰겠다 — parse()에 zod 스키마 하나 넘기면 5줄이 강제되고 usage로 건당 비용이 바로 나와 "1천 건이면 $5"를 추정이 아니라 실측으로 말할 수 있다. 키는 함수 뒤에만 두면 되고 브라우저는 /api 하나만 부른다(네트워크 탭 실측). 스트리밍 채팅이면 Vercel AI SDK를, AWS 청구 체계 안에서 돌려야 하면 Bedrock을 보겠다. 모델은 같은 입력으로 실측한 뒤 고른다 — Sonnet 5가 Opus 5와 결과 동등·시간 절반·비용 1/3이었다. 다만 "URL → 리뷰 자동"처럼 데이터 접근권이 막힌 문제는 호출 경로로 풀리지 않는다 — 그건 데이터 API를 사는 문제다.
