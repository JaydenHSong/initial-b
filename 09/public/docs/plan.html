01누가 쓰나

사진에서 색 조합을 찾고 싶은 디자이너나 제작자. 참고 이미지를 모을 때마다 각 사진의 대표색을 확인한다.

02지금은

참고 사진을 열고 색을 눈으로 고르거나 별도 편집기에서 찍는다. 다음 사진으로 넘어갈 때 이전 색 조합은 따로 적어둬야 한다.

03없앨 동작 하나

사진별 대표색의 HEX 코드를 하나씩 찍어 메모장에 옮기는 동작.

04핵심 기능 1개

이미지 파일이나 직접 이미지 URL을 넣으면 대표색 5개를 추출해 팔레트 카드로 보드에 저장하고, 색을 누르면 HEX 코드를 복사한다. 브라우저 IndexedDB에 저장해 같은 브라우저에서 다시 연다.

05안 만드는 것 3개

  • 로그인과 기기 간 동기화
  • 공유 보드와 협업
  • 색상 수동 편집과 이름 변경

06성공 판정

  • JPG·PNG·WEBP 파일을 올리면 대표색 5개와 이미지 카드가 추가된다.
  • 공개 이미지 URL을 붙여넣어도 같은 결과가 나온다.
  • HEX 행을 누르면 코드가 복사되고 완료 표시가 나온다.
  • 새로고침 뒤 같은 브라우저에서 저장된 카드가 다시 열린다.

07내 옵션 + 이유

대표색 추출은 Color Thief가 맡고, 사용자가 모은 사진과 다섯 색은 브라우저 IndexedDB에 저장한다. 서버 DB와 로그인 없이 핵심 흐름을 시연할 수 있다. React + Vite는 한 화면 UI를 구성하는 데 썼다.

08리스크 + 검증법

걱정되는 것: 이미지 URL을 제공하는 사이트가 브라우저의 외부 읽기를 막을 수 있다.
검증: 실제 공개 이미지 URL로 5색 추출과 저장을 확인했다. 일반 웹페이지 URL에는 이미지 주소 복사 안내를 보여주고, 접근이 막히면 파일 업로드를 안내한다.
