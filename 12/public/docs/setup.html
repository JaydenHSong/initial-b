Claude에 갤러리 연결하기

공식 TypeScript MCP SDK 2.3.1 · Streamable HTTP · Claude Code.
공개 갤러리를 읽으므로 API 키나 DB 관리자 권한이 필요하지 않습니다.

1. 원격 서버 연결

claude mcp add --transport http gallery https://initial-b12.vercel.app/api/mcp

Claude Code를 새로 열고 /mcp에서 gallery가 연결되었는지 확인하세요. 자연어 질문을 입력하고 도구 호출 권한을 허용하세요.

이번 주에 누가 뭘 만들었어?
이번 주 완성도가 가장 높은 사람은 누구야?
S11 제출물도 비교해줘.

2. 연결 설정 예시

HTTP MCP를 지원하는 클라이언트의 설정 형태입니다. Claude Desktop은 사용하는 버전에 따라 커넥터 추가 화면에서 원격 URL을 등록합니다. 이 프로젝트에서 실제 검증한 AI 클라이언트는 Claude Code입니다.

{
  "mcpServers": {
    "gallery": {
      "type": "http",
      "url": "https://initial-b12.vercel.app/api/mcp"
    }
  }
}

3. 로컬 stdio로 실행

소스 폴더 12/에서 의존성을 설치합니다. Node.js 24를 권장합니다.

npm ci
npm run build
npm start

로컬 클라이언트 설정의 경로는 자신의 체크아웃 절대 경로로 바꾸세요. stdout은 MCP 통신에만 씁니다.

{
  "mcpServers": {
    "gallery": {
      "command": "/absolute/path/to/node",
      "args": ["--import", "/absolute/path/to/initial-b/12/node_modules/tsx/dist/loader.mjs", "/absolute/path/to/initial-b/12/stdio.ts"]
    }
  }
}

4. Inspector에서 확인

npm run inspect:list
npm run inspect:call
npx @modelcontextprotocol/inspector --cli https://initial-b12.vercel.app/api/mcp --transport http --method tools/list
npx @modelcontextprotocol/inspector --cli https://initial-b12.vercel.app/api/mcp --transport http --method tools/call --tool-name get_gallery_submissions --tool-arg sprint=S11

브라우저 Inspector: npx @modelcontextprotocol/inspector → Streamable HTTP → 원격 주소 입력 → Connect → List Tools → Call Tool.

도구 입력·결과

도구 이름: get_gallery_submissions
입력: {}는 이번 주, {"sprint":"S11"}는 지정 주차. S01~S18만 허용합니다.

{
  "sprint": "S12",
  "count": 0,
  "status": "no_submissions",
  "submissions": []
}

위 결과는 2026-10-29 확인 당시의 실제 응답 중 일부입니다. 새 제출이 생기면 다음 도구 호출에서 다시 조회합니다. 전체 응답에는 조회 시각, 출처, 평가 한계, 리포트 누락 필드가 포함됩니다. 연결 전후 시연 기록 →

완성도 질문의 범위

갤러리 DB에 마지막 제출된 기획서·리포트의 공개 메타데이터만 조회합니다. 실제 제품 기능·화면·MCP 실행을 테스트하지 않습니다. 리포트의 ‘문서 품질’은 스택 공식 문서 평가이며 제품 완성도 점수가 아닙니다. 기록이 부족하면 최고 완성자를 판정할 수 없다고 답합니다.

배포

Vercel 프로젝트 initial-b12, Root Directory 12, Node.js 24, Output Directory public. 소개 페이지·문서는 정적 호스팅, /api/mcp는 Node.js Function입니다. Git 배포를 연결할 때는 Settings → Git → Skip deployments를 켜고 ignoreCommand는 쓰지 않습니다.
