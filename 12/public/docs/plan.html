01누가 쓰나

금요일 데모를 준비하며 팀원들이 이번 주에 무엇을 제출했는지 확인하는 팀원.

02지금은

갤러리에서 프로젝트 카드와 기획서·리포트를 각각 연다. 소요 시간은 기록 없음.

03없앨 동작 하나

이번 주 제출물을 확인하려고 여러 카드와 문서를 오가는 동작.

04핵심 기능 1개

Claude가 자연어 질문에 따라 get_gallery_submissions를 호출하면 실제 공개 제출 기록과 출처를 받아 답한다.

05안 만드는 것 3개

  • 쓰기·수정·삭제 도구
  • 자체 채팅 UI·MCP 클라이언트
  • 여러 데이터 소스·도구 묶음 및 별도 순위 시스템

06성공 판정

  • Inspector 도구 목록·실제 호출, Claude의 호출 입력·결과·답변, 같은 질문의 연결 전후 비교를 확인한다.

07내 옵션 + 이유

기존 JavaScript 계열 작업과 맞춰 TypeScript를 쓴다. Vercel의 Streamable HTTP에 같은 서버를 연결하고 로컬 stdio도 제공한다. SDK 2.3.1은 현재 설치 환경에서 검증한 버전이다.

08리스크 + 검증법

걱정되는 것: 이번 주 제출물이 비어 있거나 리포트 정보만으로 제품 완성도를 단정하는 경우.
