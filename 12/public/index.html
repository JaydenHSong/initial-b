01 / 이번 주 제출물

갤러리 일정과 미국 LA 날짜로 이번 주를 정합니다. 제출자, 제목, 소개, 스택과 기획서·리포트 링크를 가져옵니다. 제출물이 없으면 0개라고 답합니다.

02 / 완성도 비교

확인한 기록 안에서 비교

리포트의 막힌 지점과 결론, 누락된 기록을 함께 봅니다. 제품을 직접 실행한 평가는 아닙니다. 근거가 부족하면 최고 완성자를 판정할 수 없다고 답합니다.

Claude에 도구 하나 연결하면 됩니다.

Claude Code에서 프로젝트 폴더를 열고 아래 명령으로 연결하세요. 별도 API 키는 필요하지 않습니다.

claude mcp add --transport http gallery https://initial-b12.vercel.app/api/mcp

연결 주소: https://initial-b12.vercel.app/api/mcp
입력 예시: {} 또는 {"sprint":"S11"} · Inspector·로컬 stdio 설정 보기 →

작게 만들고, 끝까지 연결합니다.
